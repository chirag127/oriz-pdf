About this project

oriz-pdf

A free PDF toolkit — merge, split, rotate, reorder, extract, images to PDF — that runs entirely in your browser. This page is about the project; the live tool lives at pdf.oriz.in.

Open the live app Source on GitHub llms.txt

What it is

oriz-pdf is a client-only PDF toolkit. Drop your files onto a blueprint-style drafting table, arrange page cards on the assembly strip, and export — all without uploading anything.

Key features

  • Merge + reorder — drag pages across multiple files into one PDF.
  • Split — one output file per N pages, downloaded as a batch.
  • Rotate — per-page rotation baked into the output.
  • Extract pages — keep or delete any pages.
  • Extract text — text per page as .txt, plus optional AI summary + filename hint.
  • Extract images — pull embedded raster images out as PNG.
  • Images to PDF — drop PNG/JPG, get a page-per-image PDF.

Tech

  • Client-only Astro static site with React islands.
  • PDF work via pdf-lib + pdfjs-dist, lazy-loaded on use.
  • Optional AI via @chirag127/oz-ai (g4f multi-provider failover, no API key).
  • PWA-installable with an offline service worker.
  • 100% in-browser — no upload, no signup, free.

Your files never leave your device. Every operation runs locally in your browser; there is no server-side processing and no account.
